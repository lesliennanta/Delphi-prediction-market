# Delphi

A prediction market dashboard inspired by the design standards of Polymarket
and Kalshi, built with Next.js, TypeScript, and Tailwind CSS.

## Design

The palette is built on two tones, layered over a near-black base for a
trading-terminal feel:

- **Dollar Green** — primary brand accent, "Yes" outcomes, positive movement
- **Dollar Grey** — neutral surfaces, "No" outcomes, secondary text

## Features

- Sticky navbar with search and account actions
- Live-style scrolling price ticker
- Market stats bar (total volume, 24h volume, open markets, traders)
- Category tabs (Trending, Politics, Sports, Crypto, Culture, Business, Science, World)
- Market cards with probability bar, sparkline trend, and Yes/No buy buttons
- Sidebar with top movers, leaderboard, and market creation CTA

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
